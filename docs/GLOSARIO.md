# Glosario

- Entrenamiento: datos utilizados para ajustar el modelo.
- Validación: datos utilizados para comparar variantes y elegir el modelo.
- Test: datos reservados para evaluar el modelo seleccionado.
- Precisión: proporción de predicciones positivas que son correctas.
- Recall: proporción de casos positivos que el modelo logra detectar.
- F1: media armónica entre precisión y recall.
- MLflow: herramienta para registrar experimentos y gestionar modelos.
- API: interfaz que permite enviar solicitudes al modelo y recibir resultados.
